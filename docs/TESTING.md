# Testing

| Suite       | Command              | What it covers                                                                                                                                                                                                                                                                                                                                                                            |
| ----------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unit        | `npm test`           | Domain rules (every PRD penalty example, rounding, DST/midnight, plans, counting, identity, streaks, analytics, notification planner), parsers (LeetCode response, Striver sheet DOM in both layouts, manual input), formatting, React views with real data                                                                                                                               |
| Property    | (part of `npm test`) | fast-check invariants: total = Σ days, grace never charged, prefix-stable fold, idempotent recompute, exact rounding vs BigInt, calendar round-trip in 5 zones, order-independent counting                                                                                                                                                                                                |
| Integration | (part of `npm test`) | Real Dexie on fake-indexeddb: migrations (v1→v2 on real data), use cases, catch-up idempotency, late-data revisions, router sender rules, LeetCode sync throttles/backoff, notifications once-only, backup/restore/corruption, 1-year performance                                                                                                                                         |
| Coverage    | `npm run coverage`   | Domain ≥ 95% lines / ≥ 90% branches (CI-enforced)                                                                                                                                                                                                                                                                                                                                         |
| E2E         | `npm run test:e2e`   | Real Chrome with the unpacked extension: full 7-day lifecycle across simulated midnights, popup, LeetCode connect (mocked GraphQL, no cookies), Striver ticks on recorded markup, duplicates, reminders + badge, settings/theme, history, backup → reset → restore, worker stopped mid-challenge (CDP), axe accessibility (dark + light, every screen), release-build smoke + size budget |

E2E uses `wxt build --mode e2e` (test clock enabled) and the release build `.output/chrome-mv3` (test clock refused). Locally set `CHROME_PATH` to Chrome for Testing; CI uses Playwright's Chromium.

Rules: domain logic test-first; never weaken a test to pass; never report tests that did not run.
